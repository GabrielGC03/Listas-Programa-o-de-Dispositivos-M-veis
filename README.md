# Exercícios de Flutter

Projeto com os 5 exercícios de fixação sobre **Listas, ListView e Cards**.

## Estrutura

- `lib/main.dart` — menu para acessar os exercícios.
- `lib/exercicio1.dart` — lista de linguagens de programação.
- `lib/exercicio2.dart` — catálogo de livros com `Livro` e `Card`.
- `lib/exercicio3.dart` — lista de alunos com nome e nota.
- `lib/exercicio4.dart` — cadastro e remoção dinâmica de tarefas.
- `lib/exercicio5.dart` — cadastro e remoção de produtos do estoque.

## Como executar

1. Tenha o Flutter SDK instalado.
2. Abra a pasta do projeto no VS Code.
3. No terminal, execute:

```bash
flutter pub get
flutter run
```

Você pode executar em um celular, emulador ou Chrome.

## Como colocar no GitHub

Depois de criar um repositório vazio no GitHub:

```bash
git init
git add .
git commit -m "Exercicios de Flutter - Listas e Cards"
git branch -M main
git remote add origin URL_DO_SEU_REPOSITORIO
git push -u origin main
```

Substitua `URL_DO_SEU_REPOSITORIO` pela URL do seu repositório.

## Observação

O projeto usa apenas recursos do Flutter, sem pacotes externos adicionais.
